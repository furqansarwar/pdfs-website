Split PDF Online

Use PDFS Split PDF to make a new document from selected pages of an existing PDF. This is helpful when you only need a chapter, a few forms, or specific pages from a longer file.

Use Split PDF
Before you start: The page-range field accepts individual page numbers and ranges separated by commas. For example, 1-3,5 selects pages 1, 2, 3, and 5. Check the page count of your original PDF before entering ranges, and review the output after processing.

How to split pdf

  1. Open Split PDF on the PDFS homepage.
  2. Choose one PDF file from your device.
  3. Enter the page numbers or ranges you want, for example 1-3,5,7-9.
  4. Continue and download the PDF containing the selected pages.

What this PDF tool does

The page-range field accepts individual page numbers and ranges separated by commas. For example, 1-3,5 selects pages 1, 2, 3, and 5. Check the page count of your original PDF before entering ranges, and review the output after processing.

Important limitations

The current tool extracts the page ranges you specify into a new PDF. It does not split every page into separate downloads or edit the content within a page. Invalid or out-of-range page numbers may cause processing to fail.

Frequently asked questions

How do I select several page ranges?

Separate each page number or range with commas, such as 1-3,5,7-9.

Can I extract one page?

Yes. Enter a single page number, such as 4.

Does splitting change the original PDF?

No. The tool creates a new output file and leaves your original file on your device.
